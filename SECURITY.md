# Security Policy

## Reporting Security Vulnerabilities

We take the security of `Jailbreaker` seriously. If you discover a vulnerability or security bug in this framework, please report it responsibly instead of opening a public GitHub issue.

### How to Report
Please email security concerns to the maintainers or submit a private security advisory via GitHub:
- **Private Security Advisory**: Navigate to the **Security** tab of the GitHub repository and click **Report a vulnerability**.

### Response Process
- We will acknowledge receipt of your report within 48 hours.
- We will provide a status update and estimated resolution timeframe.
- An advisory and patch release will be published once resolved.
